# 松灵 NERO 七轴机械臂 · LeRobot 适配与示教数据链路

> 把「人手拖拽示教」变成「可训练的高质量数据集」——从遥操作采集、时间对齐、质量审计，
> 到 LeRobot v2.1 数据集规范、模仿学习训练与实机评估的完整链路。

**作者**：郑伟（厦门工学院 · 人工智能）　**角色**：项目负责人 / 数据与训练全流程　**周期**：2026.08 – 至今

---

## 一、项目概览

为七轴协作机械臂（松灵 NERO ×2，主从双臂 + AgxGripper 夹爪）搭建一套从采集到可训练数据集的完整数据链路，
支撑 ACT / pi0.5 等模仿学习策略的训练与实机评估。

核心工作不是"把模型训起来"，而是**把原始操作过程转化为高质量、可复现、体积可控的训练数据**。

| 维度 | 规模 |
|---|---|
| 示教条数 | 300 条（每条 20 秒） |
| 有效帧数 | **179,911 帧**（30 Hz） |
| 数据源 | 双机位彩色视频 + 逐帧关节状态 + 实际下发动作 |
| 原始体积 | 85.45 GB（PNG 序列） |
| 最终体积 | **3.42 GB**（压缩 25 倍） |
| 字段维度 | 状态 8 维 / 物体位置 14 维 / 动作 8 维 |
| 训练 / 验证 | 240 / 60 |

---

## 二、数据链路

```text
遥操作（120 Hz 控制）
   ↓ 逐帧落盘：图像 + 关节角 + 实际下发动作 + 时间戳 + 帧龄
原始采集（PNG + JSONL）
   ↓ 时间对齐：30 Hz 网格重采样，过期帧拒绝
   ↓ 质量过滤：帧龄 > 200 ms 丢弃、首尾异常裁剪
   ↓ 编码：h264 crf18 / yuv444p / GOP 2
   ↓ Schema 映射：LeRobot v2.1 数据集规范
标准化数据集（3.42 GB）
   ↓ 离线标签生成（物体位置）
训练集 / 验证集
```

**关键设计：采集与标注解耦。** 采集阶段只落原始数据，位置标签在事后离线生成。
这样检测算法迭代时**不需要重新采集**——重新生成标签即可。这一决策让后续 4 轮检测算法改进零采集成本。

## 三、四个关键结论

### 1. 25 倍压缩，且对下游任务无损

PNG 序列单条 285 MB，无法支撑批量训练。改视频编码后：

| 配置 | 体积 | 压缩比 | PSNR | 目标边缘偏移 |
|---|---:|---:|---:|---:|
| PNG 原始 | 174.9 MB / 条 | 1× | — | — |
| **h264 crf18 yuv444p** | **7.27 MB / 条** | **24×** | **43.6 dB** | **≤ 0.5 px** |

验证方式不是只看体积，而是逐帧比对压缩前后的像素差与目标检测结果：像素均值差 0.004，
35 px 级目标的检测框中心偏移不超过 0.5 px。

> 选 yuv444p 而非默认 yuv420p：目标依赖颜色分割，色度下采样会直接损害可检测性。

### 2. 字段的组织方式，决定下游能不能用

同一批 14 维物体位置信息，两种 Schema 布局下模型对它的响应差 20 倍以上：

| 方案 | 结构 | 位置信息响应 |
|---|---|---:|
| A. 分离式 | 状态 8 维 + 环境 14 维，两个独立字段 | 0.4% |
| **B. 合并式（采用）** | 状态 22 维（14 维拼入状态） | **8.46%** |
| C. 关系式 | 18 维手工构造的相对特征 | 未解决，弃用 |

同样的数值，放在独立字段里模型几乎不用（容器位置仅 0.07%）；并入主状态字段后提升到 8.46% 与 2.72%，
约 21 倍与 39 倍。

### 3. 用指标描述"数据有多脏"

建立 6 项审计指标，而不是凭感觉判断数据质量：

| 指标 | 实测值 | 影响与处理 |
|---|---|---|
| 相机掉帧 | 190/300 条存在 24.5–27 fps 波动，过期帧占 8.3% | 下游按帧龄 > 200 ms 拒绝 |
| 静止帧占比 | 20.3% | 影响损失分布，评估时需分层 |
| 夹爪状态滞后 | 约 2 帧 | 训练用指令值而非测量值 |
| 目标检出率（方块） | 38.6%（含跟踪补帧 64.0%） | 抓取后被遮挡属物理不可见 |
| 目标检出率（容器） | 95.3% | 容器始终可见 |
| 干扰目标 | 61/300 条含球，球检出率 20.1% | 需专门误检治理 |

**误检治理案例**：蓝色印花与蓝色干扰球颜色几乎相同，包围盒法会吞掉真球、轮廓填充法盖不住贴边印花，
两种常规方法都失败。最终改为**判别斑块外围的棕色占比**——印花位于棕色袋面（0.224），球位于白桌（0.000），
阈值取 0.08，两类目标完全分离。

### 4. 下游验证：数据链路真的能训出策略

| 方案 | 可训练参数 | 25 帧关节误差 |
|---|---:|---:|
| **ACT（本项目）** | 52 M | **1.68°** |
| pi0.5 + LoRA（3B 模型） | 7.18 M | 5.84° |
| 基线（保持不动） | — | 1.74° |

## 四、目录结构

```text
src/lerobot/            上游 LeRobot 库 + NERO 适配
  nero_tools/           采集、转换、审计、标定、颜色检测
    episode_capture.py  双机位逐帧采集（图像 + 关节 + 动作 + 时间戳）
    convert_episodes.py 原始采集 -> LeRobot v2.1 数据集（裁剪/缩放/抽帧/两种 Schema）
    env_state_schema.py 标签字段定义与版本管理（legacy14 / relation_v2）
    color_detector.py   颜色分割 + 棕色占比判别的目标定位
examples/nero/          遥操作入口、网页控制台、夹爪与起始位姿标定脚本
tools/                  诊断与审计脚本（CAN 通道、双机位、数据分布、标签校验）
configs/                训练与数据配置（base14 / pi05 / LoRA）
docs/                   设计文档、交接文档、操作说明
media/                  图标与静态资源
```

## 五、快速开始

在 Windows + Miniconda 环境（Python 3.12，RTX 4090）下验证：

```bat
:: 1) 环境（conda 未初始化到 PATH 时用完整路径）
D:\miniconda\envs\lerobot\python.exe -V

:: 2) 设置导入路径（必须指向本仓库）
set "PYTHONPATH=%CD%\src;%CD%\tools"

:: 3) 打开只监听本机的双臂网页控制台
start_nero_control_center.cmd

:: 4) 命令行遥操作（主臂 -> 从臂）
python examples\nero\teleoperate.py
```

> 网页控制台不是实体急停。遥操作前必须通过页面中的只读身份检查。
