# 腕部抓取离线检查（2026-11-01）

范围：episode_0000、0004、0007，各 600 帧，共 1800 帧，按时间连续检测；未连接机械臂。
方法：HSV 红色分割、3x3 开闭运算、轮廓筛选、相邻帧候选关联。
对近距离目标移除旧检测器的 25% 图像面积上限，允许贴边的部分轮廓；贴边时不提供可用于完整目标定位的中心。
候选突然跳变时拒绝；超过 0.2 秒未接受新候选后允许重新获取。多个相近候选标 ambiguous。缺失时不输出缓存目标框。
这只是启发式候选检测，不是训练后的实例识别，也不具备遮挡完整性判断：不贴图像边缘的候选仍可能被夹指遮挡。
localization_usable 仅表示通过当前几何检查，不能据此自动运动。

实图查看确认 0000 的第 240 帧此前漏检，现在能找到红色区域，但框触及图像边缘，不能据此计算真实物块中心。

当前不能完成的判断：

- 暗色最大轮廓会把地面/袋子阴影当夹指，已从新审核图移除，不作为抓取中心。
- 多张照片只有一侧夹指清晰，不能从两指中点获得可靠标定。
- 数据未采集深度，不能从单张二维图获得可靠抓取高度。
- 图像中有物块和夹爪开口变化，不足以证明物块被夹紧；需同步回放 base/wrist、状态变化，之后再验证力/电流是否可用。

下一步建议：人工确认成功抓取的连续片段，联看 base/wrist 和夹爪开口，确定闭合、抬起和物块是否随动；仅有 auto_end 不算成功标签。
可先从已审核成功片段研究腕部目标出现区域与开口的关系，但不能把部分出画面的框平均成固定抓取中心。
如果临近闭合时物块持续出画面，后续应实测调整腕部相机视角或采用标定后的几何控制；改变相机视角会造成训练分布变化，不能直接沿用旧图像模型。
不把本模块加入 base14 字段，也不改变现有 ACT 数据集；这是独立诊断试验。
