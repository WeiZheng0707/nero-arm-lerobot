# NERO 环境启动说明

这台机器上 conda **没有初始化到 PATH**（没有 PowerShell profile），所以默认状态下
`conda activate` 用不了，每次都得手打完整路径。下面三个脚本就是为了解决这个。

## 日常使用：双击 `start_nero_env.cmd`

双击后会打开一个已经就绪的 CMD 窗口：

- Python 指向 `D:\miniconda\envs\lerobot\python.exe`
- 项目目录已 `cd` 进来
- `PYTHONPATH` 已设为 `src;tools`
- `PATH` 已优先指向 lerobot 环境
- 会先自检一次 `import lerobot`，editable 装歪了会立刻警告

进去之后直接敲命令即可，不用再带完整路径：

```bat
python -c "import lerobot; print(lerobot.__file__)"
python -X utf8 -m pytest -q -p no:cacheprovider src\lerobot\nero_tools\test_episode_capture.py
python -X utf8 tools\realsense_bandwidth_check.py --list
```

## 环境体检：双击 `check_nero_env.cmd`

一次跑完五步并把结果存到 `verify_output.txt`：

1. Python 版本与解释器路径
2. 修复 `lerobot` editable 安装（`pip install -e . --no-deps`）
3. 导入自检（`lerobot` / `pyAgxArm` / `can` / `draccus` / `torch`）
4. 离线测试（不连硬件）
5. RealSense 相机枚举（只读，不连机械臂）

**换电脑或搬动项目后先跑这个。**

## 它是怎么找到 Conda 的：`_nero_env.bat`

被上面两个脚本调用，不要直接双击。查找顺序：

1. 项目根目录的 `.nero_conda_path.txt`（上次成功的路径，秒开）
2. 常见安装位置：`D:\miniconda`、`D:\Miniconda3`、`C:\ProgramData\miniconda3`、
   `%USERPROFILE%\miniconda3` 等
3. 从 PATH 里的 `conda` 反推根目录

找到后会把根目录写进 `.nero_conda_path.txt` 缓存。

> **注意**：旧 `.bat` 里写的是 `D:\Miniconda`（大写），你的实际路径是 `D:\miniconda`（小写）。
> Windows 路径不区分大小写，所以**这些旧脚本其实能正常工作**，不用改。
> 新脚本统一用自动定位，更不容易出问题。

## 如果 Conda 装在别的地方

直接新建 `.nero_conda_path.txt`，写一行 Conda 根目录（不含 `\envs`）：

```
E:\somewhere\miniconda3
```

或者在 `_nero_env.bat` 第 30 行附近的位置列表里加一行。

## 环境关键事实（核对用）

| 项 | 路径 / 值 |
|---|---|
| Conda 根目录 | `D:\miniconda` |
| 环境 Python | `D:\miniconda\envs\lerobot\python.exe` |
| 激活脚本 | `D:\miniconda\Scripts\activate.bat` |
| 项目根目录 | 本文件所在目录 |
| editable 安装 | `lerobot_nero 0.1.0`，`.pth` 指向本项目 `src` |

**已知坑：** 备份解压时多套了一层同名目录，`site-packages\lerobot_nero.pth`
原来指向空的内层 `...\lerobot_nero_standalone_backup_20261019_before_changes\lerobot_nero_standalone_backup_20261019_before_changes\src`，
导致 `import lerobot` 直接失败。跑一次 `check_nero_env.cmd` 即可修复。

## 手动等价命令（不想用脚本时）

```bat
cd /d "C:\Users\Administrator\Desktop\lerobot_nero_standalone_backup_20261019_before_changes"
set "PYTHONPATH=%CD%\src;%CD%\tools"
set "PYTHONIOENCODING=utf-8"
D:\miniconda\envs\lerobot\python.exe -V
```

如果想让 `conda activate lerobot` 长期可用，可以执行一次初始化（会改 PowerShell profile）：

```bat
D:\miniconda\Scripts\conda.exe init powershell
```

然后重开终端。**这一步是可选的**，上面三个脚本不依赖它。
